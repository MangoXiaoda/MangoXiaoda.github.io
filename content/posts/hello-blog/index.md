这是新博客的第一篇示例文章。前台使用 Hugo 和 Dream 主题生成，后台使用 Decap CMS 管理 Markdown 内容。

<!--more-->

你可以把文章写成旅行记录、技术笔记或照片日记。上传的图片会进入 `static/img/uploads`，发布后路径会变成 `/img/uploads/...`。

> [!NOTE]
> 点击左上角头像可以翻转到关于页面，文章里的图片也支持点击放大。

## 写作流程

1. 本地启动 Hugo 预览站点。
2. 打开 `/admin/` 进入 Decap CMS。
3. 新建文章、上传封面、填写分类和标签。
4. 提交到 Git 后，GitHub Actions 自动构建并发布。

## 下一步

把 `hugo.toml` 里的站点名称、头像、域名和 Waline 地址换成你的实际信息，这个博客就可以变成自己的版本。
